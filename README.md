# optionallabs.com

The website for Optional Labs, the company behind ZeroAuth, Saifu, Parchi and Tegami.

Static HTML, CSS and JavaScript with no build step. GitHub Pages deploys `main` (see `.github/workflows/static.yml`) to the custom domain in `CNAME`. Markdown files, `tools/` and repo metadata are not published.

## Update a product page

Edit the facts in `tools/build-products.py`, then run `python3 tools/build-products.py`. Share images are rendered by `node tools/make-og.mjs` (needs Playwright).

## Run locally

```sh
python3 -m http.server 8080
# open http://localhost:8080
```

## Layout

| Path | What it is |
| --- | --- |
| `index.html` | Homepage: the hub that lists every product |
| `zeroauth/`, `saifu/`, `parchi/`, `tegami/` | Product detail pages, generated by `tools/build-products.py` |
| `privacy-policy.html` | Privacy policy |
| `sitemap.xml`, `robots.txt` | Search engine files |
| `tools/` | Page and share-image generators (not published) |
| `app-ads.txt` | Ad network declaration for the apps |
| `assets/` | CSS, JS, fonts, icons, app screens and share images (`og/`) |
| `PRODUCT.md` | Product facts the site is written from |
